# 剪贴板功能

> 状态：已实现
> 依赖：`@react-native-clipboard/clipboard`
> 平台：iOS · Android · Web

## 概述

项目封装了剪贴板功能，提供了声明式的 `useClipboard` Hook 和可复用的 `CopyButton` 组件，支持所有平台的剪贴板读写操作。

## 安装

依赖已在项目根目录安装，无需额外操作。

```bash
# 如需重新安装
pnpm add @react-native-clipboard/clipboard -w
```

## API

### useClipboard Hook

声明式 Hook，用于在函数组件中使用剪贴板功能。

```typescript
import { useClipboard } from '@myapp/shared';

function Example() {
  const { data, setString, getString, hasString } = useClipboard();

  return (
    <View>
      <Text>剪贴板内容：{data || '空'}</Text>
      <Button title="复制文本" onPress={() => setString('Hello World')} />
      <Button title="读取剪贴板" onPress={getString} />
    </View>
  );
}
```

#### 返回值

| 属性 | 类型 | 说明 |
|------|------|------|
| `data` | `string \| null` | 当前剪贴板内容，自动更新 |
| `setString` | `(text: string) => Promise<void>` | 写入剪贴板 |
| `getString` | `() => Promise<string \| null>` | 读取剪贴板 |
| `hasString` | `() => Promise<boolean>` | 检查是否有内容 |

### CopyButton 组件

封装好的复制按钮组件，提供多种样式和功能配置。

```typescript
import { CopyButton } from '@myapp/shared';

function Example() {
  return (
    <CopyButton
      text="https://example.com"
      label="复制链接"
      copiedLabel="已复制"
      showAlert={true}
      onCopied={() => console.log('复制成功')}
      variant="primary"
      size="medium"
    />
  );
}
```

#### Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `text` | `string` | 必填 | 要复制的文本 |
| `label` | `string` | `'复制'` | 按钮文字 |
| `copiedLabel` | `string` | `'已复制'` | 复制后显示的文字（2秒） |
| `onCopied` | `() => void` | - | 复制成功回调 |
| `showAlert` | `boolean` | `false` | 是否显示系统提示 |
| `variant` | `'primary' \| 'secondary' \| 'outline'` | `'primary'` | 按钮样式 |
| `size` | `'small' \| 'medium' \| 'large'` | `'medium'` | 按钮大小 |
| `style` | `ViewStyle` | - | 自定义样式 |
| `textStyle` | `TextStyle` | - | 自定义文字样式 |
| `disabled` | `boolean` | `false` | 是否禁用 |

## 直接使用 Clipboard API

如需在非组件环境中使用，可直接导入原始库：

```typescript
import Clipboard from '@react-native-clipboard/clipboard';

// 写入
await Clipboard.setString('文本内容');

// 读取
const text = await Clipboard.getString();

// 检查
const hasContent = await Clipboard.hasString();
```

## 示例

### 1. 基础使用

```tsx
import { View, Text } from 'react-native';
import { useClipboard, CopyButton } from '@myapp/shared';

function ShareScreen() {
  const { data } = useClipboard();

  return (
    <View>
      <Text>当前剪贴板：{data || '空'}</Text>
      <CopyButton text="分享内容" />
    </View>
  );
}
```

### 2. 自定义样式

```tsx
<CopyButton
  text="邀请码: ABC123"
  label="复制邀请码"
  variant="outline"
  size="small"
  showAlert={true}
  onCopied={() => analytics.track('copy_invite_code')}
/>
```
