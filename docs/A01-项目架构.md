# 项目架构

> 状态：✅ 已实现（2026-05-24 同步）  
> 构建工具：**Nx**（替代 Turborepo）

## 设计目标

- **apps / packages 分层**：可部署应用与共享库分离
- **多平台扩展**：`apps/app` 为主应用，预留 windows / macos / harmony
- **代码共享**：`packages/shared`、`packages/jsbridge`
- **Nx 任务编排**：build / lint / test / typecheck 统一调度

## 架构图

```
┌──────────────────────────────────────────────────────────────┐
│                        Monorepo 根目录                        │
├──────────────────────────────────────────────────────────────┤
│  apps/                    可部署应用                          │
│    app/    @myapp/app     Android · iOS · RNW                │
│    web/    @myapp/web     独立 H5（React Router）             │
│    (windows / macos / harmony — 规划中)                       │
├──────────────────────────────────────────────────────────────┤
│  packages/                共享库                              │
│    shared/   @myapp/shared    组件 · hooks · MST · theme      │
│    jsbridge/ @myapp/jsbridge  H5 ↔ App 通信 SDK              │
└──────────────────────────────────────────────────────────────┘
         │                              │
         ▼                              ▼
   Metro / Gradle / Xcode          Webpack / Rspack
   (android/ ios/ 在根目录)         (:3000 / :3002)
```

## Nx 项目

| 项目 | 类型 | 路径 |
|------|------|------|
| `@myapp/app` | application | `apps/app` |
| `@myapp/web` | application | `apps/web` |
| `@myapp/shared` | library | `packages/shared` |
| `@myapp/jsbridge` | library | `packages/jsbridge` |

```bash
nx run @myapp/web:build
nx run-many -t typecheck
nx graph
```

## 双 Web 路径

| 命令 | 应用 | 工具 | 端口 |
|------|------|------|------|
| `pnpm dev:web` | `@myapp/web` | Webpack | 3000 |
| `pnpm dev:app:web` | `@myapp/app` | Rspack | 3002 |

## 多平台扩展规划

| 平台 | 规划路径 | 技术 |
|------|----------|------|
| Windows | `apps/windows` | react-native-windows |
| macOS | `apps/macos` | react-native-macos |
| HarmonyOS | `apps/harmony` | react-native-harmony |

详见 [apps/README.md](../apps/README.md)。

## 常用命令

```bash
pnpm install
pnpm dev:app
pnpm dev:web
pnpm android
pnpm typecheck
pnpm build:web
pnpm graph
```
