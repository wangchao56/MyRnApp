# 项目架构

> 状态：✅ 已实现（2026-05-24 同步）

## 设计目标

- **一套业务代码多平台复用**：Android、iOS、Web 共享 `@myapp/shared`
- **独立迭代**：App 原生、独立 H5、JSBridge 各自成包
- **WebView 嵌入**：App 内嵌 H5，通过 `@myapp/jsbridge` 通信
- **状态管理**：MobX State Tree（MST）统一状态与主题

## 架构图

```
┌─────────────────────────────────────────────────────────────┐
│                      Monorepo 根目录                         │
├─────────────────────────────────────────────────────────────┤
│  packages/shared     共享层（组件、hooks、models、theme）    │
│  packages/jsbridge   JSBridge SDK（H5 侧 + 分享适配器）      │
│  packages/app        原生 App + RNW（React Navigation）     │
│  packages/web        独立 H5 站点（React Router）            │
└─────────────────────────────────────────────────────────────┘
         │                    │                    │
         ▼                    ▼                    ▼
    Android / iOS         Rspack RNW           Webpack H5
    (Metro)               :3002                :3002 → :3000
```

## 双 Web 路径

项目有两条 Web 开发/构建路径，职责不同：

| 命令 | 包 | 工具 | 端口 | 导航 | 用途 |
|------|-----|------|------|------|------|
| `pnpm dev:web` | `@myapp/web` | Webpack | 3000 | React Router | 独立 H5、Bridge 联调页 |
| `pnpm dev:app:web` | `@myapp/app` | Rspack | 3002 | React Navigation | 完整 App 的 Web 版 |

## JSBridge 通信

```
H5 (@myapp/web 或外部页面)
    │  jsbridge.invoke('getUserInfo')
    ▼
HybridWebView (packages/app)
    │  bridgeHandlers
    ▼
App 原生能力 (Share API, Alert, mock scan...)
```

- H5 SDK：`packages/jsbridge`（ESM / CJS / UMD）
- App handlers：`packages/app/src/bridge/bridgeHandlers.ts`
- 详见 [`packages/jsbridge/README.md`](../packages/jsbridge/README.md)

## 常用命令

```bash
pnpm install          # 安装依赖
pnpm dev:app          # Metro 原生开发
pnpm android          # 运行 Android
pnpm ios              # 运行 iOS（macOS）
pnpm dev:web          # 独立 H5 开发 (:3000)
pnpm dev:app:web      # App RNW 开发 (:3002)
pnpm dev:all          # 并行启动 app + web
pnpm build:web        # 构建 @myapp/web
pnpm build:jsbridge   # 构建 JSBridge UMD
pnpm typecheck        # 类型检查
pnpm lint             # 代码检查
```
