# 📦 React Native 官方打包机制详解

## 🎯 核心打包工具

React Native 使用 **Metro Bundler** 作为官方 JavaScript 打包工具，配合原生平台的构建系统完成最终打包。

---

## 🔧 打包架构

```
┌─────────────────────────────────────────────────────────────┐
│                    React Native 打包流程                    │
├─────────────────────────────────────────────────────────────┤
│  1. Metro Bundler                                          │
│     ├── 入口文件 (index.js)                                 │
│     ├── 依赖解析 (resolver)                                │
│     ├── 代码转换 (transformer)                             │
│     └── 输出 Bundle (main.jsbundle / index.android.bundle)  │
│                              ↓                             │
│  2. 原生构建系统                                            │

│     └── iOS: Xcode (xcbuild) + CocoaPods                   │
│                              ↓                             │
│  3. 最终产物                                                │
│     ├── Android: .apk / .aab                               │
│     └── iOS: .ipa                                          │
└─────────────────────────────────────────────────────────────┘
```

## 🚀 核心打包工具：Metro Bundler

### 1. 什么是 Metro

**Metro** 是 Facebook 专为 React Native 打造的 JavaScript 打包工具：

- ⚡ 快速增量打包
- 🔄 热更新支持
- 🎯 专为 React Native 优化

### 2. 项目中的 Metro 配置

查看你的 [metro.config.js](file:///Users/tianhe/work/hqfront/metro.config.js)：

```javascript
module.exports = {
  resolver: {
    assetExts: [
      'db',
      'mp3',
      'ttf',
      'obj',
      'png',
      'jpg',
      'gltf',
      'bin',
      'glb',
      'html',
    ],
    extraNodeModules: {
      stream: require.resolve('readable-stream'),
    },
  },
};
```

### 3. Metro 打包命令

```bash
# 开发模式启动
npx react-native start

# 生成 iOS Bundle
react-native bundle \
  --entry-file index.js \
  --platform ios \
  --dev false \
  --bundle-output ios/main.jsbundle \
  --assets-dest ios

# 生成 Android Bundle
react-native bundle \
  --platform android \
  --dev false \
  --entry-file index.js \
  --bundle-output android/app/src/main/assets/index.android.bundle \
  --assets-dest android/app/src/main/res
```

## 📱 原生平台构建

### 1. Android 构建 - Gradle

**构建工具**：Gradle + Android Gradle Plugin

**项目配置**：

```bash
# 调试构建
cd android && ./gradlew assembleDebug

# 发布构建
cd android && ./gradlew assembleRelease  # 你的项目命令
```

**构建产物**：

- `android/app/build/outputs/apk/release/app-release.apk`

### 2. iOS 构建 - Xcode

**构建工具**：Xcode (xcbuild) + CocoaPods

**项目配置**：

```bash
# 使用 fastlane（你的项目）
cd ios && fastlane beta

# 或直接使用 xcodebuild
xcodebuild -workspace MyApp.xcworkspace -scheme MyApp -configuration Release
```

**构建产物**：

- `.ipa` 文件（用于 App Store 提交）

## 🔄 完整打包流程

### 开发模式

```
1. npm start → Metro 启动开发服务器
2. npm run run-android/run-ios → 原生构建
3. 应用启动时从 Metro 服务器加载 JS 代码
4. 热更新：代码变化时自动刷新
```

### 生产模式

```
1. react-native bundle → 生成离线 JS Bundle
2. gradle/xcodebuild → 整合 Bundle 和原生代码
3. 生成最终安装包 (.apk/.ipa)
4. 签名打包（用于发布）
```

## 🧩 代码转换流程

```
源文件 (.tsx/.jsx)
       ↓
┌─────────────────────────────────────┐

│  ├── Babel: ES6+ → ES5             │
│  ├── TypeScript → JavaScript       │

└─────────────────────────────────────┘
       ↓
打包后的 Bundle (.jsbundle)
       ↓
注入原生应用
```
