## 测试场景列表

### 场景 1: 保存测试图片

**测试步骤**:
1. 连接 Android 设备并启动应用
2. 点击底部导航的 "Media" 标签
3. 点击 "📷 保存图片" 按钮
4. 首次使用时，授权存储权限
5. 等待保存完成
6. 检查相册

**预期结果**:
- ✅ 权限请求弹窗显示
- ✅ 授予权限后，图片保存成功
- ✅ 显示成功提示："成功 - 图片已保存到相册！"
- ✅ 相册中出现 "MyRnApp Test" 相册
- ✅ 相册中包含测试图片

**测试数据**:
- URL: `https://picsum.photos/800/600?random=100`
- 类型: photo
- 相册: MyRnApp Test

### 场景 2: 保存测试视频

**测试步骤**:
1. 在 MediaTestScreen 页面
2. 点击 "🎬 保存视频" 按钮
3. 授权存储权限（如果尚未授权）
4. 等待视频下载并保存
5. 检查相册

**预期结果**:
- ✅ 视频开始下载和保存
- ✅ 显示成功提示："成功 - 视频已保存到相册！"
- ✅ 相册中视频可见
- ✅ 可以播放保存的视频

**测试数据**:
- URL: `https://www.w3schools.com/html/mov_bbb.mp4`
- 类型: video
- 相册: MyRnApp Test

### 场景 3: 权限处理（Android）

**测试步骤**:
1. 首次在 Android 设备上点击保存按钮
2. 观察权限请求弹窗
3. 拒绝权限
4. 再次点击保存按钮
5. 观察错误处理

**预期结果**:
- ✅ 首次点击时显示权限请求
- ✅ 拒绝权限后显示错误
- ✅ 错误信息清晰
- ✅ 可以重试操作

**Android 权限需求**:
- Android 13+ (API 33+):
  - READ_MEDIA_IMAGES
  - READ_MEDIA_VIDEO
- Android 12 及以下:
  - WRITE_EXTERNAL_STORAGE
  - READ_EXTERNAL_STORAGE

### 场景 4: 状态管理测试

**测试步骤**:
1. 点击 "📷 保存图片"
2. 观察加载状态
3. 等待保存完成
4. 观察成功状态
5. 点击 "🔄 重置状态"
6. 观察状态重置

**预期结果**:
- ✅ 加载时显示 ActivityIndicator
- ✅ 成功后显示绿色成功框
- ✅ 重置后所有状态清空
- ✅ UI 正确响应所有状态变化

### 场景 5: 错误处理测试

**测试步骤**:
1. 断开网络连接
2. 点击保存按钮
3. 观察错误处理
4. 恢复网络连接
5. 再次尝试保存

**预期结果**:
- ✅ 显示明确的错误信息
- ✅ 错误状态正确显示
- ✅ 恢复网络后可正常保存
- ✅ 错误信息友好且可操作

### 场景 6: 平台检测测试

1. 在 Android 设备上查看平台信息

**预期结果**:
- ✅ Platform.OS === 'android'
- ✅ 显示 Android 特定的权限处理说明
- ✅ UI 正确适配 Android 平台

## 测试执行流程

```bash
# 确保 Metro Bundler 运行
cd e:\workspace\MyRnApp
pnpm dev:app

# 检查设备连接
adb devices
```

### 步骤 2: 启动应用
```bash

pnpm android

# 或安装 APK 后手动运行

./gradlew installDebug
```
