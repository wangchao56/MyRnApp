# 通用图片组件

## 概述

提供多个图片组件，适用于不同场景：

| 组件 | 说明 | 推荐场景 |
|------|------|----------|
| **OssImage** | 集成阿里云 OSS 图片处理 | 生产环境（App + H5） |
| **FastOssImage** | 基于 FastImage 的高性能版本 | 性能要求高的场景 |
| **ImagePreview** | 独立的图片预览弹出 | 需要查看大图/多张图片 |
| **SmartImage** | 简洁易用的通用组件 | 快速开发 |

---

## OssImage（⭐推荐用于 App + H5）

基于你的项目需求优化，集成了阿里云 OSS 图片处理能力。

### 安装依赖

```bash
pnpm add react-native-fast-image
```

### 基本用法

```tsx
import { OssImage } from '@myapp/shared';

<OssImage
  source="https://example.aliyuncs.com/image.jpg"
  style={{ width: 200, height: 200 }}
/>
```

### Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `source` | `ImageSource` | 必填 | 图片来源 |
| `style` | `ImageStyle` | - | 图片样式 |
| `containerStyle` | `ViewStyle` | - | 容器样式 |
| `resizeMode` | `'cover' \| 'contain' \| 'stretch' \| 'center'` | `'cover'` | 填充模式 |
| `isPreview` | `boolean` | `false` | 预览模式（使用 thumb 样式） |
| `skipSize` | `boolean` | `false` | 跳过尺寸处理 |
| `notChangeSource` | `boolean` | `false` | 不修改源地址 |
| `customSuffix` | `string` | - | 自定义 OSS 参数 |
| `placeholder` | `'loading' \| 'skeleton' \| 'none'` | `'loading'` | 占位类型 |
| `skeletonColor` | `string` | - | 骨架屏颜色 |
| `fallbackSource` | `ImageSource` | - | 备用图片 |
| `onLoad` | `() => void` | - | 加载成功回调 |
| `onError` | `(error) => void` | - | 加载失败回调 |
| `onPress` | `() => void` | - | 点击回调 |
| `fadeIn` | `boolean` | `true` | 淡入动画 |
| `fadeInDuration` | `number` | `250` | 淡入时长(ms) |

## FastOssImage（高性能版）

基于 `react-native-fast-image`，提供更好的缓存和性能控制。

### Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `source` | `ImageSource` | 必填 | 图片来源 |
| `style` | `ImageStyle` | - | 图片样式 |
| `containerStyle` | `ViewStyle` | - | 容器样式 |
| `resizeMode` | `'cover' \| 'contain' \| 'stretch' \| 'center'` | `'cover'` | 填充模式 |
| `isPreview` | `boolean` | `false` | 预览模式 |
| `skipSize` | `boolean` | `false` | 跳过尺寸处理 |
| `notChangeSource` | `boolean` | `false` | 不修改源地址 |
| `customSuffix` | `string` | - | 自定义 OSS 参数 |
| `placeholder` | `'loading' \| 'skeleton' \| 'none'` | `'loading'` | 占位类型 |
| `skeletonColor` | `string` | - | 骨架屏颜色 |
| `fallbackSource` | `ImageSource` | - | 备用图片 |
| `onLoad` | `() => void` | - | 加载成功回调 |
| `onError` | `(error) => void` | - | 加载失败回调 |
| `onPress` | `() => void` | - | 点击回调 |
| `fadeIn` | `boolean` | `true` | 淡入动画 |

### 示例

```tsx
import { FastOssImage } from '@myapp/shared';

<FastOssImage
  source="https://example.aliyuncs.com/image.jpg"
  style={{ width: 200, height: 200 }}
  priority="high"
/>
```

## ImagePreview（图片预览组件）

独立的图片预览弹出组件，支持单张或多张图片预览。

### 基本用法 - 单张图片

```tsx
import { useState } from 'react';
import { OssImage, ImagePreview } from '@myapp/shared';

function MyComponent() {
  const [previewVisible, setPreviewVisible] = useState(false);

  return (
    <>
      <OssImage
        source="https://example.aliyuncs.com/image.jpg"
        style={{ width: 200, height: 200 }}
        onPress={() => setPreviewVisible(true)}
      />
      <ImagePreview
        visible={previewVisible}
        images={['https://example.aliyuncs.com/image.jpg']}
        onClose={() => setPreviewVisible(false)}
      />
    </>
  );
}
```

### 多张图片预览 - 推荐用法

```tsx
import { useState } from 'react';
import { View, StyleSheet } from 'react-native';
import { OssImage, ImagePreview } from '@myapp/shared';

function ProductGallery() {
  const [previewVisible, setPreviewVisible] = useState(false);
  const [previewIndex, setPreviewIndex] = useState(0);

  const images = [
    'https://example.aliyuncs.com/img1.jpg',
    'https://example.aliyuncs.com/img2.jpg',
    'https://example.aliyuncs.com/img3.jpg',
  ];

  const handleImagePress = (index: number) => {
    setPreviewIndex(index);
    setPreviewVisible(true);
  };

  return (
    <View style={styles.container}>
      {images.map((url, index) => (
        <OssImage
          key={index}
          source={url}
          style={{ width: 100, height: 100 }}
          isPreview={true}
          onPress={() => handleImagePress(index)}
        />
      ))}
      
      <ImagePreview
        visible={previewVisible}
        images={images}
        initialIndex={previewIndex}
        onClose={() => setPreviewVisible(false)}
        showIndicator={true}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flexDirection: 'row',
    flexWrap: 'wrap',
    padding: 10,
  },
});
```

### Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `visible` | `boolean` | 必填 | 是否显示预览 |
| `images` | `Array<ImageSource>` | 必填 | 图片数组（支持单张或多张） |
| `initialIndex` | `number` | `0` | 初始显示的图片索引 |
| `onClose` | `() => void` | 必填 | 关闭回调 |
| `backgroundColor` | `string` | `'rgba(0, 0, 0, 0.95)'` | 背景颜色 |
| `closeButtonStyle` | `any` | - | 关闭按钮样式 |
| `closeButtonTextStyle` | `any` | - | 关闭按钮文字样式 |
| `showIndicator` | `boolean` | `true` | 是否显示位置指示器（如 1/3） |

### 功能特性

1. **左右滑动切换** - 使用 ScrollView 实现平滑滑动
2. **点击导航** - 左右箭头按钮快速切换
3. **位置指示器** - 显示当前页码（如 2/5）
4. **支持多种图片来源** - 字符串 URL、本地图片、对象形式

## 图片处理工具函数

### processSource

自动处理图片 URL：

```tsx
import { processSource } from '@myapp/shared';

const url = processSource(
  'https://example.aliyuncs.com/image.jpg',
  200,  // width
  150,  // height
  false, // isPreview
  { skipSize: false }
);
```

### extractSizeFromStyle

从样式中提取宽高：

```tsx
import { extractSizeFromStyle } from '@myapp/shared';

const { width, height } = extractSizeFromStyle({
  width: 200,
  height: 150
});
```

### 配置 OSS 参数

```tsx
import { setImageConfig } from '@myapp/shared';

setImageConfig({
  ossSuffix: {
    normal: [
      '?x-oss-process=style/x1',
      '?x-oss-process=style/x2',
      '?x-oss-process=style/x3',
    ],
    preview: [
      '?x-oss-process=style/thumb_x1',
      '?x-oss-process=style/thumb_x2',
      '?x-oss-process=style/thumb_x3',
    ],
  },
  enableResize: true,
  enableQuality: true,
});
```

### isOssImage / isGifImage

判断图片类型：

```tsx
import { isOssImage, isGifImage } from '@myapp/shared';

isOssImage('https://example.aliyuncs.com/image.jpg'); // true
isGifImage('https://example.com/animation.gif'); // true
```

## 完整示例：产品相册

```tsx
import { useState } from 'react';
import { View, StyleSheet, Text } from 'react-native';
import { OssImage, ImagePreview } from '@myapp/shared';

function ProductGallery() {
  const [previewVisible, setPreviewVisible] = useState(false);
  const [previewIndex, setPreviewIndex] = useState(0);

  const productImages = [
    {
      thumb: 'https://example.aliyuncs.com/product1-thumb.jpg',
      original: 'https://example.aliyuncs.com/product1.jpg',
    },
    {
      thumb: 'https://example.aliyuncs.com/product2-thumb.jpg',
      original: 'https://example.aliyuncs.com/product2.jpg',
    },
    {
      thumb: 'https://example.aliyuncs.com/product3-thumb.jpg',
      original: 'https://example.aliyuncs.com/product3.jpg',
    },
  ];

  const handleImagePress = (index: number) => {
    setPreviewIndex(index);
    setPreviewVisible(true);
  };

  return (
    <View style={styles.container}>
      <Text style={styles.title}>产品图片 ({productImages.length})</Text>
      
      <View style={styles.gallery}>
        {productImages.map((image, index) => (
          <OssImage
            key={index}
            source={image.thumb}
            style={{ width: 100, height: 100 }}
            isPreview={true}
            onPress={() => handleImagePress(index)}
          />
        ))}
      </View>
      
      <ImagePreview
        visible={previewVisible}
        images={productImages.map(img => img.original)}
        initialIndex={previewIndex}
        onClose={() => setPreviewVisible(false)}
        showIndicator={true}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    padding: 16,
  },
  title: {
    fontSize: 16,
    fontWeight: '600',
    marginBottom: 16,
  },
  gallery: {
    flexDirection: 'row',
    flexWrap: 'wrap',
    gap: 10,
  },
});

export default ProductGallery;
```
