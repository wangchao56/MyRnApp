## Monorepo 特殊说明

本项目为 **pnpm workspace + Nx**，原生工程在仓库根目录（`android/`、`ios/`），JS 入口在根目录 `index.js`，应用源码在 `apps/app/`。

### Metro 必须从根目录启动

RN CLI 在 `apps/app` 子目录下无法注册 `start` 命令（缺少 `android/`、`ios/`）。已在 `apps/app/package.json` 中处理：

```json
"dev": "pnpm --dir ../.. exec react-native start --no-interactive"
```

### Webpack / Rspack 不受 RN 升级直接影响

| 路径 | 工具 | 配置位置 |
|------|------|----------|
| `@myapp/web` | Webpack 5.107.0 | `apps/web/webpack.config.js` |
| `@myapp/app` RNW | Rspack | 根目录 `rspack.config.js` |
| 原生 App | Metro | 根目录 `metro.config.js` |

## 本地验证步骤

### 1. 安装依赖

```bash
pnpm install
```

### 2. 清理缓存（升级后建议执行一次）

```bash
pnpm clean:cache
```

### 3. Metro

```bash
pnpm dev:app
```

### 4. Android

```bash
pnpm android
# 或
pnpm dev:android
```

**注意**：minSdk 已升至 **24**，不再支持 Android 7.0 以下设备。

### 5. iOS（macOS）

```bash
cd ios && pod install && cd ..
pnpm ios
```

若 Pod 安装失败，尝试：

```bash
cd ios
rm -rf Pods Podfile.lock build
pod install --repo-update
```

### 6. Web 回归

```bash
pnpm dev:web          # 独立 H5
pnpm dev:app:web      # App RNW
pnpm typecheck        # TypeScript
```

```bash
cd ios && pod install && cd ..
```

## RN 0.77 主要变化（与本项目相关）

| 变化 | 影响 |
|------|------|
| Android autolinking 重构 | `settings.gradle` + `autolinkLibrariesWithApp()` |
| `RCTAppDependencyProvider` | iOS 必须集成，否则第三方原生模块可能运行时异常 |
| minSdk 24 | 丢弃 API 23 设备 |
| Kotlin 2.0 | 与 AGP 8.7+ 配套 |
| CLI 15.x | `react-native start/run-android` 行为与 13.x 略有差异 |
| 默认新架构模板 | 本项目**刻意保持关闭**，降低迁移风险 |

更多版本背景见 [A04-各大版本之间的区别](./A04-各大版本之间的区别.md)。
