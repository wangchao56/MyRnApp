要在 React Native 和 React Native Web 中同时实现扫码功能，面临的主要挑战是**底层硬件 API 完全不同**：原生端调用的是 iOS/Android 的底层相机（AVFoundation / CameraX），而 Web 端调用的是浏览器的 `getUserMedia` 和 WebRTC 接口。

目前没有一个绝对“完美”且零配置的单一库，但行业内主要有两种主流解决方案：

## 方案一：使用 Expo Camera（最推荐的统一方案）

即使你没有使用 Expo 框架（即 Bare React Native 项目），也可以通过配置 `expo-modules` 来安装 Expo 的相机库。这是目前对多端（iOS、Android、Web）兼容性最好的**一站式解决方案**。

_注：以前通常使用 `expo-barcode-scanner`，但它在较新的版本中已被废弃，现在扫码功能已完全合并入 `expo-camera`。_

### 安装方式

```bash
# 如果是 Expo 项目
npx expo install expo-camera

# 如果是纯 React Native 项目，需要先安装 expo 核心模块
npx install-expo-modules
npm install expo-camera
```

### 为什么推荐？

它在底层做了抹平：在 iOS/Android 上调用原生高性能相机，在 Web 端自动降级调用浏览器摄像头，并通过引入 WebAssembly 或纯 JS 库（如 ZXing）来解析二维码。你只需要写一套代码：

```javascript
import {CameraView, useCameraPermissions} from 'expo-camera';
import {View, Text, StyleSheet} from 'react-native';

export default function App() {
  const [permission, requestPermission] = useCameraPermissions();

  if (!permission?.granted) {
    return <Text onPress={requestPermission}>请求相机权限</Text>;
  }

  return (
    <View style={StyleSheet.absoluteFillObject}>
      <CameraView
        style={StyleSheet.absoluteFillObject}
        barcodeScannerSettings={{
          barcodeTypes: ['qr'],
        }}
        onBarcodeScanned={result => {
          console.log('扫码结果: ', result.data);
        }}
      />
    </View>
  );
}
```

## 方案二：按平台分别引入（追求极致性能的方案）

如果对原生端扫码速度要求极高，Expo Camera 的性能可能不够用。最佳实践是“原生与 Web 分开处理”。

项目已采用此方案的 **Web 部分**（`Scanner.web.tsx` + `html5-qrcode`），Native 部分待实现。

### 1. 原生端 (`Scanner.native.tsx`)

使用 **`react-native-vision-camera`**：

```bash
pnpm add react-native-vision-camera
```

### 2. Web 端 (`Scanner.web.tsx`) — ✅ 已实现

使用 **`html5-qrcode`**（已安装）。

### 3. 调用方式

```javascript
import { Scanner } from '@myapp/shared';

export default function MyScanPage() {
  return <Scanner onScanSuccess={data => console.log(data)} />;
}
```

## 方案对比建议

| 需求场景 | 推荐方案 | 优点 | 缺点 |
| -------- | -------- | ---- | ---- |
| 快速上线，代码统一 | 方案一：`expo-camera` | 维护成本低，一套代码跑三端 | 原生端扫码性能中等 |
| 需要工业级极限扫码速度 | 方案二：分离加载 | 原生端性能拉满 | 需维护两套 UI 和相机生命周期 |
