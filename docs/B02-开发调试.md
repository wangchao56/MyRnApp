# React Native 调试工具详解

React Native 提供了多种调试工具，涵盖官方和社区两个层面：

---

## 📋 核心调试工具

### 1. **Flipper** - 官方推荐调试工具 🎯

**简介**：Facebook 官方推出的跨平台调试工具，是目前最强大的调试工具。

**功能**：

- 🔍 布局检查器 (Layout Inspector)
- 📊 网络请求监控
- 📱 原生日志查看
- 📝 数据库可视化
- 🎨 像素完美工具
- 🔌 插件生态系统

**安装与使用**：

```bash
# 1. 下载 Flipper 桌面应用
# 访问: https://fbflipper.com/

# 2. 在项目中安装依赖
npm install react-native-flipper --save-dev

# 3. 在 iOS 中配置
cd ios && pod install
```

**在项目中启用**（参考你的项目）：

你的项目可能已包含相关配置，通常在 `metro.config.js` 或 `index.js` 中：

```javascript
// 启用 Flipper
if (__DEV__) {
  import('react-native-flipper');
}
```

---

### 2. **React Native Debugger** - 社区主流工具

**简介**：基于官方调试器构建的独立应用，集成了 Redux DevTools。

**安装**：

```bash
# macOS
brew install --cask react-native-debugger

# 或者访问 GitHub 下载
# https://github.com/jhen0409/react-native-debugger
```

**使用**：

```bash
# 启动后，运行命令连接
open "rndebugger://set-debugger-loc?host=localhost&port=8081"
```

---

### 3. **Chrome DevTools** - 原生调试器

**使用方式**：

- 在模拟器中按 `Cmd + D`（iOS）或 `Cmd + M`（Android）
- 选择 "Debug" 或 "Debug JS Remotely"
- Chrome 会自动打开 DevTools

---

### 4. **React DevTools** - 组件检查工具

**功能**：

- 组件树可视化
- Props 和 State 实时查看
- 组件层级分析

```bash
# 安装
npm install -g react-devtools

# 运行
react-devtools
```

---

## 🛠️ 其他调试工具

### 5. **性能监控工具**

- **Flipper Performance Monitor**：帧率、CPU、内存监控
- **React Native Performance Monitor**：性能数据分析

### 6. **日志调试**

```javascript
// console.log - 基础日志
console.log('Debug info', data);

// console.warn - 警告
console.warn('Warning message');

// console.error - 错误
console.error('Error occurred');
```

**Reactotron 功能**：

- 📊 **MST 状态跟踪** - 支持 MobX State Tree
- 📱 **AsyncStorage 查看** - 查看本地存储数据
- 🔧 **自定义命令** - 重置状态、导航等
- 📝 **日志查看** - 应用内日志
- 🖼️ **图片查看** - 显示图片
- ⏱️ **性能计时** - 代码执行时间

**使用方式**：

```javascript
// 在代码中使用
console.tron.log('调试信息', data);
console.tron.display({name: '自定义', value: data});
console.tron.error('错误信息', error);
console.tron.warn('警告信息');
console.tron.benchmark('测试性能', () => {
  // 你的代码
});
```

**项目已配置的自定义命令**（来自代码）：

- `resetStore` - 重置 Root Store
- `resetNavigation` - 重置导航状态
- `goBack` - 返回上一页
