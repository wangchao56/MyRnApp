# React Native 媒体保存功能

> 状态：⚠️ 部分实现  
> 最后同步：2026-05-24

## 当前实现

| 平台 | 状态 | 说明 |
|------|------|------|
| Web（`@myapp/web`） | ❌ | `useSaveMedia.web.ts` 返回 `isSupported: false` |
| Web（App RNW） | ⚠️ | 默认 hook 使用浏览器下载 API |
| Android | ❌ | 未接入 `@react-native-camera-roll/camera-roll` |
| iOS | ❌ | 未接入 CameraRoll |

## 已有代码

| 文件 | 说明 |
|------|------|
| `packages/shared/src/hooks/useSaveMedia.ts` | Hook 接口 + 浏览器下载逻辑 |
| `packages/shared/src/hooks/useSaveMedia.web.ts` | Web 平台 stub（不支持） |
| `packages/app/src/screens/MediaSaveTestScreen.tsx` | 测试页（底部 Tab「Media」） |
| `android/app/src/main/AndroidManifest.xml` | 已声明存储权限 |

## Hook 用法

```typescript
import { useSaveMedia } from '@myapp/shared';

const { saveMedia, isLoading, error, success, reset } = useSaveMedia();

await saveMedia('https://example.com/image.jpg', { type: 'photo' });
```

## ⏳ 待实现（Native）

1. 安装 `@react-native-camera-roll/camera-roll`
2. 在 `useSaveMedia.ts` 中按平台分支：
   - Android：请求 `READ_MEDIA_IMAGES` / `WRITE_EXTERNAL_STORAGE` 权限
   - iOS：调用 `CameraRoll.save()`
3. 更新 `useSaveMedia.web.ts` 或在 RNW 环境启用浏览器下载

参考方案见 [Android测试指南](./Android测试指南.md)。
