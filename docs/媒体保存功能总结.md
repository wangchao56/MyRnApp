# React Native 媒体保存功能 - 完整实现总结

## ✅ 已完成的工作

### 1. 核心 Hook 实现
**文件**: `packages/shared/src/hooks/useSaveMedia.ts`

```typescript
import { useSaveMedia } from '@myapp/shared';

const MyComponent = () => {
  const { saveMedia, isLoading, error, success, reset } = useSaveMedia();

    } catch (err) {

  };

```

#### iOS 环境

- 保存到相册

## 🔍 技术细节

### 权限处理逻辑

```typescript
// Android 13+ (API 33+)
PermissionsAndroid.PERMISSIONS.READ_MEDIA_IMAGES
PermissionsAndroid.PERMISSIONS.READ_MEDIA_VIDEO

// Android 12 及以下
PermissionsAndroid.PERMISSIONS.WRITE_EXTERNAL_STORAGE
PermissionsAndroid.PERMISSIONS.READ_EXTERNAL_STORAGE
```

### 保存选项

```typescript
interface SaveMediaOptions {
  type?: 'photo' | 'video';
  album?: string;  // 可选，指定相册名称
}
```

### 返回状态

```typescript
interface UseSaveMediaReturn {
  saveMedia: (uri: string, options?: SaveMediaOptions) => Promise<void>;
  isLoading: boolean;  // 保存中
  error: string | null;  // 错误信息
  success: boolean;  // 是否保存成功
  reset: () => void;  // 重置状态
}
```

## 🎯 使用示例

### 基本使用
```typescript
import { useSaveMedia } from '@myapp/shared';

function ImageGallery() {
  const { saveMedia } = useSaveMedia();

  const handleSave = async (imageUrl) => {
    await saveMedia(imageUrl, { type: 'photo' });
  };
}
```

### 高级使用
```typescript
import { useSaveMedia } from '@myapp/shared';

function VideoPlayer() {
  const { saveMedia, isLoading, error, success, reset } = useSaveMedia();

  const handleSaveVideo = async (videoUrl) => {
    try {
      await saveMedia(videoUrl, {
        type: 'video',
        album: 'MyApp Videos'
      });
      Alert.alert('成功', '视频已保存到相册');
    } catch (err) {
      Alert.alert('错误', `保存失败: ${err.message}`);
    }
  };

  return (
    <View>
      <Button 
        title="保存视频" 
        onPress={handleSaveVideo}
        disabled={isLoading}
      />
      {isLoading && <Text>正在保存...</Text>}
      {success && <Text>保存成功！</Text>}
      {error && <Text>错误: {error}</Text>}
    </View>
  );
}
```

## 🐛 故障排除

### 问题：权限请求没有弹出
**解决方案**: 检查 `AndroidManifest.xml` 中的权限声明

### 问题：保存失败，提示权限被拒绝
**解决方案**: 
- 确保添加了所有必需权限
- Android 13+ 需要 `READ_MEDIA_IMAGES` 和 `READ_MEDIA_VIDEO`
- 手动在设置中授予应用存储权限

### 问题：应用崩溃
**解决方案**:
- 确保 Metro Bundler 正在运行
- 检查 `@react-native-camera-roll/camera-roll` 版本
- 查看终端错误日志

### 问题：找不到保存的文件
**解决方案**:
- 检查 "MyRnApp Test" 相册
- 或使用文件管理器查看 `DCIM/MyRnApp Test` 目录
